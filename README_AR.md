# غِراس — مشروع Android أولي قابل للتطوير

تطبيق عربي أصلي بلغة Java، بواجهة خضراء زمردية وذهبية، ويشمل في هذه النسخة:
- واجهة رئيسية.
- تحديات يومية مع حفظ الإنجاز محليًا.
- شجرة رمزية تتدرج بحسب عدد التحديات المكتملة في اليوم.
- شاشة قرآن تعرض سورة الفاتحة كنموذج واجهة فقط.
- شاشة مواقيت صلاة توضح أن الحساب لم يُفعّل بعد.

## مهم جدًا: ما لم يكتمل بعد
هذه **نسخة أساس قابلة للتطوير وليست تطبيقًا نهائيًا جاهزًا للنشر**:
1. لم تُدمج بعد نسخة كاملة موثوقة من نص القرآن، والفاتحة الظاهرة مجرد نموذج.
2. تنزيل التلاوات وتشغيلها غير مفعّل بعد.
3. مواقيت الصلاة واتجاه القبلة والتنبيهات لم تُفعّل بعد.
4. لم يتم بناء APK أو اختباره على جهاز فعلي ضمن عملية إعداد هذا المشروع.

## المتطلبات
- Android Studio حديث.
- JDK 17.
- اتصال بالإنترنت لأول مزامنة Gradle وتنزيل Android Gradle Plugin.
- Android SDK Platform 35.

## فتح المشروع
1. فك ضغط `GhirasAndroid.zip`.
2. افتح Android Studio.
3. اختر **Open** وحدد مجلد `GhirasAndroid` الذي يحتوي `settings.gradle`.
4. وافق على Gradle Sync وثبّت SDK 35 إذا طُلب.
5. شغّل التطبيق على محاكي أو هاتف مع تفعيل USB debugging.

## بناء APK تجريبي
من Android Studio:
1. من القائمة اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
2. انتظر انتهاء البناء.
3. سيعرض Android Studio إشعارًا فيه **locate** لفتح مجلد APK.
4. جرّب APK على جهاز فعلي قبل توزيعه.

أو من طرفية المشروع بعد إعداد Android SDK:
- Windows: `gradlew.bat assembleDebug`
- Linux/macOS: `./gradlew assembleDebug`

المسار المعتاد بعد نجاح البناء:
`app/build/outputs/apk/debug/app-debug.apk`

لا يوجد Gradle Wrapper مرفق في هذه الحزمة؛ يمكن إنشاءه من Android Studio أو باستخدام `gradle wrapper` عند توفر Gradle محليًا.

## خطة الإكمال المقترحة
1. إدراج نص قرآني كامل من مصدر موثوق مع توثيق المصدر ومراجعة النص.
2. دمج مكتبة حساب مواقيت موثوقة واختبارها في الجزائر وفق طريقة الحساب المختارة.
3. إضافة اختيار القارئ وتنزيل ملفات الصوت وإدارة مساحة التخزين.
4. إضافة الإشعارات واتجاه القبلة واختبار العمل بعد إعادة تشغيل الهاتف.
5. اختبار RTL، أحجام الخطوط، الأجهزة المختلفة، وحالات عدم وجود الإنترنت.
